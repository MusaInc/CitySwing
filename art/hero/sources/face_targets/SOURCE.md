# Facial shape targets

MakeHuman 1.x modelling targets (head, nose, mouth, chin, cheeks, eyebrows,
forehead, neck), fetched unmodified from
https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data/targets
(file name = `<folder>_<target>.target`). MakeHuman's graphical assets,
including these targets, are CC0 (see ../LICENSE.md). Used by
tools/blender/build_character.py to shape the selectable faces.
